# LIMTV · 桌面版影视播放器

Windows 桌面应用，**双击就是一个独立窗口，不经过浏览器**。不需要账号、不上传任何数据，观看记录、播放进度、收藏、片单全部存在自己电脑上。

> 本仓库发布的是**纯净通用版**：不含任何片库数据和内置点播源，装完是空的，片源由你自己添加。软件本身是一个**片源可替换的播放器外壳**，不抓取、不分发任何影视资源；请只添加你有权观看的片源。

## 功能一览

### 播放体验
- **独立窗口**：WebView2 内嵌自己的窗口，无地址栏无标签页，关窗即退出、无后台残留
- **自定义播放器**：悬浮预览进度条、±10/±30 秒快进退、倍速、画中画、全屏、自动隐藏控制栏
- **清晰度切换**：4K / 2K / 1080P 固定档位 + 片源实际档位，切换不丢进度；详情页自动探测每条线路最高清晰度并标徽章
- **多线路 / 换源**：详情页列出全部播放线路，播放中可随时换源且不丢进度；线路失效自动降级到下一条
- **选集**：剧集自动拆集、选集网格、播完自动下一集；播放器里也能直接选集
- **快捷键**：`空格` 播放/暂停 · `←/→` ±10s · `↑/↓` 音量 · `F` 全屏 · `M` 静音 · `/` 搜索

### 片库与记录
- **断点续播**：精确到秒记录每部片看到哪，打开自动跳回上次位置；首页「继续观看」一键接着看
- **看完判定**：看到 95% 自动标记已看完；我的片单、观看记录独立页面
- **搜索筛选**：按片名/年份/类型搜索，叠加「未看 / 观看中 / 已看完 / 收藏」筛选；分类页按类型自动归集
- **本地片库**：把电脑里的 mp4 / mkv / webm 直接拖进窗口，进片库并记录进度
- **添加直链**：粘贴自己的 m3u8 / mp4 直链即可添加影片，支持多片源热切换

### 片源管理（自带源）
- **搜全网**：添加自己的检索接口，多源并行搜索、结果合并、搜到就能看、不入库；单源 12 秒死线，慢源不拖整体
- **导入源站**：粘贴接口地址（苹果CMS / M3U / JSON 三类）自动批量导入，支持分页、全量、增量续传
- **片源自检**：一键检测所有片源连通性，红绿点直观展示
- **去广告**：支持 TVBox ads 规则，m3u8 广告分片自动剔除，失败绝不挡播放

### 数据安全
- **本地存储**：所有数据在 `%LOCALAPPDATA%\LIMTV`，可自定义位置、随文件夹整体搬家
- **自动备份**：写库自动留备份，只增不减；启动自动校验回填，误写空库冲不掉真数据
- **省空间模式**：导入只存定位信息、首次打开才拉详情，5 万部约 40 MB（全量存要 373 MB）
- **分片存储**：十万部级片库拆「索引 + 分片」，启动只读索引，详情按需毫秒级加载

### 一起看
- **同步观影**：局域网直接开房，朋友浏览器打开链接即可同步看
- **内网穿透**：通用支持樱花 / cpolar / ngrok / cloudflared，填一条命令自动识别公网地址
- **聊天弹幕**：房间内聊天浮窗，新消息弹幕飘过；房主是权威时钟，播放/暂停/拖进度全同步

### 其他
- 深色 / 浅色 / 跟随系统三套外观，自定义壁纸
- 屏蔽成人内容：开关 + 内置/自定义关键词集中管理，全软件统一口径
- 可选跳过短剧 / 漫剧 / 解说 / 体育直播类内容

## 系统要求

Windows 10 1809+ / Windows 11（需 WebView2 运行时，系统一般已内置；缺失时自动改用默认浏览器打开）。

## 首次使用

1. 安装或解压后双击打开
2. 首次启动约 10~20 秒（单文件解包 + WebView2 冷启动），之后会快很多
3. 添加你有权观看的内容：
   - 把本地视频文件**拖进窗口**
   - 右上角「添加影片」粘贴 `m3u8` / `mp4` 直链
   - 「导入源站」/「搜全网」里添加你自己的接口地址

## 边界说明
